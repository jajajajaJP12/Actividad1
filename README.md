Actividad 1 - Listas Enlazadas

Alumno:
Jorge Pardo

Materia:
Estructuras de Datos

Descripción:

Este proyecto implementa diferentes tipos de listas enlazadas en Java.

Estructuras implementadas:

- Lista simplemente enlazada
- Lista doblemente enlazada
- Lista circular

Funcionalidades:

- Insertar elementos
- Eliminar elementos
- Buscar elementos
- Mostrar listas

Tipos de datos:

Se demuestra el uso de:

- String
- Integer
- Double
- Boolean
- Objetos (Contacto)

Gestión de Contactos:

El programa incluye un sistema sencillo para:

- Agregar contactos
- Buscar contactos
- Eliminar contactos
- Mostrar contactos

Cada contacto es un objeto con:

- Nombre
- Dirección
- Teléfono
